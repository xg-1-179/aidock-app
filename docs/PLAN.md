# AIDock 待完善清单（按「用户真正会遇到」排序）

这份清单是「先想清楚再动手」的产物：每一行写清 **为什么值得做 / 做完怎么验**，
避免为了凑功能而堆屏幕。状态只有三种：已做 / 本轮做 / 排在后面。

## P0 影响「能不能顺畅用」

| 项 | 为什么 | 怎么验 | 状态 |
|---|---|---|---|
| 发送失败可重发 | 地铁/弱网下最常发生；原来失败只留一行灰字，用户得重新打字 | 断网发一条 → 气泡下出现「没发出去，重发」 → 恢复网络点一下，只出现一条 | 本轮做 |
| 长按复制 / 引用 | 手机上没法用鼠标选中一段；引用回复是聊天软件的基本操作 | 长按任意气泡 → 复制粘贴到别处；引用后输入框出现 `> 原文` | 本轮做 |
| 多图一次发送 | 拍三张截图要发三次，且每张都单独占一条消息 | 相册多选 3 张 → 一条消息、气泡里 3 张图、宿主侧 3 个 image 块 | 本轮做 |
| 切后台回前台立刻恢复 | 锁屏十分钟回来要等看门狗（原来 30 秒才动） | 锁屏 1 分钟再回来，历史自己补上，不用手动下拉 | 已做（onResumed） |
| 挂着卡重连后仍在 | 审批/提问帧不带 seq，重连不回放，原来会「卡没了但电脑还在等」 | 断开重连后审批卡还在 | 已做（/link/pending） |

## P2 想清楚再动，别硬凑

| 项 | 卡在哪 | 打算 |
|---|---|---|
| 插件市场 | 移动端的 `/extension/catalog` 是「手机 HTML 扩展包」，跟 DSH 插件市场不是一回事；硬塞会让用户以为能装插件 | 先做只读「已装插件」列表，安装/卸载留在桌面端 |
| 真·浅色主题 | `AidockColors` 是编译期常量，散落在 20+ 个文件里；部分换会出半深半浅 | 一次性抽成 `Theme` 扩展 + `ThemeData` 两套，单独一轮做 |
| 会话归档 / 排队消息编辑 | `/session/archive` 实际是「打包 zip」，不是归档；`/session/queue/update` 要 sessionId + 队列 id 双游标 | 先确认手机端是否需要「打包下载」，不然不做 |
| 会话内搜索 | 列表是懒加载，跳到第 N 条要不精确滚动（估计高度会抖） | 用「搜索面板列出命中的消息文本」+ 点击后向下逐页加载，不做像素级定位 |
| 文件下载 | `/file/read` 回的是加密二进制流，要自己拼分块解密 | 需要单独实现分块 + 落盘 + 打开器，排在主题之后 |

## 不做

- 人在外面给新手机配对（用户明确不做）
