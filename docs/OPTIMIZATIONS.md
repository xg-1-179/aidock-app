# AIDock 优化提案（20 条）

> 先想清楚再动手。每条都写：解决什么、怎么做、成本、风险。
> 「手机操作电脑的插件」不是插件市场页写不出来的问题 —— 上游 `dsh-mobile-plugin` 已经把
> `/api/mobile/v1/plugin/*` 全套端点做齐了（清单 / 市场 / 安装 / 卸载 / 启停 / 更新进度 / 卸载进度），
> 手机端只是少了一个页面。详见第 10 条。

## 一、连接与稳定（1–4）

### 1. 切网自动重连（WiFi ↔ 4G、飞行模式恢复）
- **问题**：现在靠 10 秒心跳看门狗发现断流，切网后要等十几秒；走出 WiFi 范围时更容易卡在「重连中」。
- **做法**：监听系统网络变化（`connectivity_plus`），事件到达即主动 `_attachStream`，不等心跳；重连失败按 0.5s/1s/2s/4s 退避。
- **成本**：小（一个监听 + 复用现有 `_attachStream`）。**风险**：低。

### 2. 冷启动回到上次会话
- **问题**：重开 App 永远停在会话列表，得重新点进去、重新拉历史。
- **做法**：`SharedPreferences` 记住 `lastSessionId` + 最后可见消息 id；启动后恢复会话并定位到那条消息。
- **成本**：小。**风险**：低（会话被删则回列表）。

### 3. 后台保活加固（国产 ROM 会杀前台服务）
- **问题**：`AidockService` 已是前台服务 + `START_STICKY`，但小米/华为/OPPO 默认清理仍会杀。
- **做法**：首次连接后弹一次「电池优化」引导（`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` + 各厂商自启页跳转说明），并显示当前是否已加入白名单。
- **成本**：中（要按 ROM 分支文案）。**风险**：中（引导页做过头会被当成流氓软件，只做一次、可跳过）。

### 4. 断网待发队列
- **问题**：现在没网发送直接失败，要手动点「重发」。
- **做法**：失败消息进本地队列（带会话 id），网络恢复或重连成功后按顺序补发；队列可在「更多」里查看/清除。
- **成本**：中（要处理顺序、去重、`clientMessageId` 幂等）。**风险**：中（重复发送 → 用宿主 `/session/delivery` 回执校验）。

## 二、输入与阅读（5–9）

### 5. 草稿保存
- **问题**：写了一半切去别的会话/退出，回来全丢。
- **做法**：`SharedPreferences` 按会话存草稿（含引用前缀），进入会话回填。
- **成本**：小。**风险**：低。

### 6. 会话内 + 全局搜索
- **问题**：只能按标题过滤会话，找不到「上次说的那句话在哪」。
- **做法**：全局走宿主 `/session/search`（已有）；会话内做本地高亮 + 「跳到下一条」，历史按需逐页加载后再搜。
- **成本**：中。**风险**：中（会话内搜索要处理分页，先只搜已加载的 40 条 + 落到底）。

### 7. 代码块复制 / 全屏
- **问题**：现在代码块只能看，复制要长按整条消息。
- **做法**：代码块右上角「复制」「全屏」两颗小按钮；全屏页等宽、横屏可滚动、可分享。
- **成本**：小。**风险**：低。

### 8. 长消息折叠
- **问题**：模型一次输出几千字，滚动很累。
- **做法**：超过 12 行折起，显示「展开全部（共 N 字）」；折叠状态不记忆。
- **成本**：小。**风险**：低。

### 9. 图片查看器
- **问题**：缩略图 220px，看不清截图里的字。
- **做法**：点图进全屏（`InteractiveViewer` 双指缩放、双击放大），底部「保存到相册」「复制」。
- **成本**：小。**风险**：低（保存要 `WRITE_EXTERNAL_STORAGE`，Android 10+ 用 MediaStore）。

## 三、手机操作电脑（10–16）

### 10. 插件管理页（你点名要的）
- **问题**：手机上完全看不到电脑装了哪些插件，也不能装/卸/启停。
- **做法**：新页 `PluginsPage`，两个 tab：
  - **已安装**：`GET /api/mobile/v1/plugins` → `{items:[{entryId, moduleName, enabled, fiberPhase}], revision}`，每行「名称 + 启用开关 + fiber 状态点」，带 `?rev=` 条件请求（清单没变只回 `unchanged`，省流量）。
  - **市场**：`GET /plugin/market` → `{bundles:[{name, version, icon, title, description, source, enabled, installed, official}]}`（`icon` 是 `data:image/...`，直接 Image.memory），搜索框本地过滤；点条目进详情（`/market/detail` + `/market/versions` 选版本），「安装」调 `/market/install`（可带 `registry`，取值来自 `/market/registries`），安装中轮询 `/market/progress`，可 `/market/cancel`；已装的给「卸载」（`/market/remove`）与「启停」（`/market/enabled`）。
- **成本**：中（一个页面 + 轮询进度条）。**风险**：中 —— 安装/卸载会重启插件，**正在跑的任务可能被打断**，所以写操作前二次确认，并在进度页提示「插件会短暂重载」。
- **前置**：这些端点属宿主原路径，**必须重启一次 DSH 宿主**新配对设备才有权限（现在回 `401 e2ee-unknown-device`）。

### 11. 常用命令收藏
- **问题**：`/` 面板有 13 条命令，常用的两三条每条都要打几个字。
- **做法**：`/` 面板顶部固定「收藏」区，长按命令可收藏/取消，存本地。
- **成本**：小。**风险**：低。

### 12. 会话管理补齐（置顶 / 删除 / 导出 / 真归档）
- **问题**：现在只有改名和分叉。
- **做法**：长按菜单加「置顶」「删除会话」「导出 Markdown」（宿主 `/session/export`? 若无则前端拼接已加载历史）。归档语义要先确认：`/session/archive` 实际是**打包 zip**，不是移入归档箱。
- **成本**：中。**风险**：中（删除不可逆，必须二次确认 + 输入标题确认）。

### 13. 文件浏览与下载
- **问题**：产物页只能看路径和复制。
- **做法**：`/file/read` 返回的是**加密的二进制块**，要在客户端按协议解块再拼文件，存到 `Download/AIDock/` 或直接 `Share`；大文件走分块 + 进度。
- **成本**：大。**风险**：中（分块解密写错会产出坏文件，需要 CRC/大小校验）。

### 14. Git 写操作
- **问题**：现在只读（状态/日志/diff）。
- **做法**：加「暂存 / 提交 / 推送」；提交信息可编辑，推送前显示 ahead/behind。
- **成本**：中。**风险**：高 —— 手机上误触 push 到 main 很危险，建议默认只允许 commit，push 要二次确认 + 显示目标分支。

### 15. 定时任务新建
- **问题**：只能看列表、暂停、运行。
- **做法**：`/schedule/create` 表单（循环表达式 / 一次性时间 / 提示词 / 目标会话），编辑用 `/schedule/update`（要带 `expectedUpdatedAt` 防覆盖）。
- **成本**：中。**风险**：中（时间表达式写错会半夜跑任务）。

### 16. 后台任务页
- **问题**：电脑上跑的 job / 后台命令，手机看不到进度。
- **做法**：`GET /api/mobile/v1/monitor` + `/jobs/*` 做一个「任务」页，显示运行中/最近结束，可取消。
- **成本**：中。**风险**：低。

## 四、通知与多机（17–18）

### 17. 通知静音时段
- **问题**：任务在深夜跑完会响。
- **做法**：设置里加「静音时段」（如 23:00–08:00），到点只记日志不弹通知；审批类通知可选「仍然提醒」。
- **成本**：小。**风险**：低。

### 18. 一台手机连多台电脑（并行）
- **问题**：现在多机是「切过去」，切换会断掉上一台的流。
- **做法**：保持多条 `DshClient` 同时存活，会话列表合并分组显示（按机器名），未激活机器的通知仍能到达。
- **成本**：中大（要重构 `_client` 为 map，页面按机器过滤）。**风险**：中（内存与连接数上升，注意别把电量吃干）。

## 五、工程与体验（19–20）

### 19. 应用内自动更新
- **问题**：每次更新要我发链接、你手动下载安装。
- **做法**：启动时查 GitHub Releases 最新 tag（`/releases/latest`），有新版本显示「有新版本 · 下载」→ 下载 APK 后走 `ACTION_VIEW` 安装（Android 8+ 需要「允许安装未知应用」引导）。
- **成本**：中。**风险**：中（静默安装不行，只能引导；签名不一致会导致覆盖安装失败 —— 保持同一调试签名即可）。

### 20. 崩溃日志采集 + 一键导出
- **问题**：真机上闪退我这边什么都收不到，只能猜。
- **做法**：`FlutterError.onError` + `PlatformDispatcher.instance.onError` 写本地文件（脱敏：不含 token/凭据），「更多」页可查看/复制/导出；顺带给「运行日志」加按级别过滤。
- **成本**：小。**风险**：低（务必脱敏）。

## 建议的批次

| 批次 | 内容 | 理由 |
|---|---|---|
| 第一批 | 10 插件管理 + 1 切网重连 + 5 草稿 + 7 代码块按钮 + 8 折叠 | 你点名的功能 + 三个低风险高频痛点 |
| 第二批 | 6 搜索 + 9 图片查看器 + 17 静音 + 20 崩溃日志 | 阅读与可维护性，风险都低 |
| 第三批 | 4 待发队列 + 19 自动更新 + 11 收藏 + 15 定时任务新建 | 需要新依赖/新表单，单独一轮好回滚 |
| 暂缓 | 13 文件下载（大）、14 Git 写（危险）、18 并行多机（重构）、12 删除会话（不可逆） | 要么工程量大，要么误操作代价高 |

## 一个前提

第 10、12、15、16 条都走宿主「原路径」，需要**DSH 托盘退出重开一次**，新配对设备才有权限（现在这些端点回 `401 e2ee-unknown-device`，而 `/link/*` 别名一直可用）。
